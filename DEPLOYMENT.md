# English Step

Тренажёр английских времён: 6 тем, 36 упражнений с объяснениями на русском, повторение ошибок и словарь QA.

## Публикация на GitHub Pages

1. Откройте Settings → Pages.
2. Выберите Source: Deploy from a branch.
3. Укажите Branch: main, Folder: / (root).
4. Нажмите Save и дождитесь успешного развёртывания.

Ожидаемый адрес: https://anatolyhalak.github.io/english-step/

## Файлы

- index.html — страница и навигация.
- style.css — оформление и адаптация для телефона.
- data.js — правила, упражнения и словарь.
- app.js — тренировки, проверка ответов и локальный прогресс.

Сборка и зависимости не требуются. Для локального просмотра можно использовать VS Code Live Server или выполнить `python3 -m http.server 8000` в каталоге проекта.

Прогресс хранится в localStorage конкретного браузера. На другом устройстве, в другом браузере или на другом домене результаты не синхронизируются. Озвучивание зависит от английских голосов, доступных браузеру и устройству.
