# English Step — английский в своём темпе

**English Step** — сайт для самостоятельного изучения английских времён с объяснениями на русском языке, упражнениями и примерами из повседневной жизни и работы QA. Он помогает разобраться в смысле времён, выбрать форму глагола и закрепить правило на практике.

**Открыть тренажёр:** [anatolyhalak.github.io/english-step](https://anatolyhalak.github.io/english-step/)

**Репозиторий:** [github.com/anatolyhalak/english-step](https://github.com/anatolyhalak/english-step)

## Что есть на сайте

| Возможность | Что получает пользователь |
|---|---|
| 6 тем по грамматике | Правила, формулы, примеры и слова-подсказки для шести английских времён |
| 36 упражнений | По 6 заданий на каждое время с выбором одного из трёх вариантов |
| Объяснения ответов | Правильная форма глагола и разбор правила после каждого ответа |
| Смешанная тренировка | 10 случайных вопросов из общей базы |
| Повторение ошибок | Отдельный список заданий, в которых был выбран неверный ответ |
| Личный прогресс | Закреплённые упражнения, процент верных ответов и дни практики подряд |
| Английский для QA | 16 словарных карточек с переводами и примерами |
| Озвучивание | Произношение слов и примеров средствами браузера, если доступен английский голос |
| Адаптивное оформление | Интерфейс для компьютера, планшета и телефона |

Регистрация не требуется. Обучение и проверка ответов выполняются в браузере; отдельный сервер приложения и база данных не нужны.

## Для кого создан проект

- Для начинающих, которым удобнее изучать грамматику с объяснениями на русском.
- Для тех, кто хочет повторить базовые времена небольшими порциями.
- Для тестировщиков и других IT-специалистов, которым полезны примеры с API, багами, логами, релизами и требованиями.
- Для самостоятельной практики по 5–10 минут на одну тему; это ориентир, встроенного таймера на сайте нет.

В интерфейсе указан ориентир **A1–A2**. Это обозначение направленности материалов, а не результат определения уровня или полноценная программа подготовки по CEFR.

## Разделы сайта

### 1. Мой маршрут

Главная страница показывает текущий прогресс и помогает выбрать следующий шаг.

На ней доступны:

- **Рекомендованная тема.** Сайт предлагает первую тему по порядку, в которой закреплены ещё не все шесть упражнений.
- **Карточки всех времён.** Для каждой темы отображаются название, краткое описание и количество закреплённых заданий.
- **Общее количество закреплённых упражнений** из 36.
- **Процент верных ответов за всё время**, включая повторные попытки.
- **Количество дней практики подряд.**

Темы доступны сразу: обязательного прохождения по порядку и блокировки последующих уроков нет. После закрепления всех тем в качестве следующего шага снова предлагается первая тема — для повторения.

### 2. Времена и правила

В разделе собраны шесть уроков и блок сравнения времён на примерах с одним глаголом.

| Шаг | Время | Основной смысл | Пример из урока |
|---|---|---|---|
| 01 | Present Simple | Привычки, регулярные действия и факты | I test the API every day. |
| 02 | Present Continuous | Действие сейчас или временная ситуация | I am testing the API right now. |
| 03 | Past Simple | Завершённое действие в прошлом | I found a bug yesterday. |
| 04 | Future Simple | Решение в момент речи, обещание или прогноз с will | I will check it for you. |
| 05 | Present Perfect | Опыт или результат, связанный с настоящим | I have already fixed the bug. |
| 06 | Past Continuous | Процесс в определённый момент прошлого | I was testing when the server crashed. |

Каждый урок содержит:

1. Объяснение, когда употребляется время.
2. Формулу построения предложения.
3. Примеры утверждения, отрицания и вопроса.
4. Слова-подсказки, например `yesterday`, `right now`, `already`.
5. Пример с переводом на русский язык.
6. Пояснение особенностей и типичных ошибок.
7. Кнопку прослушивания примера.
8. Индикатор прогресса и переход к упражнениям по теме.

Материалы объясняют, что слова-маркеры помогают понять контекст, но сами по себе не всегда определяют время. Например, `tomorrow` не требует обязательного использования `will`.

### 3. Тренировка

В выпадающем списке можно выбрать один из трёх режимов.

| Режим | Состав тренировки |
|---|---|
| Отдельное время | Все 6 упражнений выбранной темы |
| Все времена | 10 случайных упражнений из общей базы в 36 заданий |
| Мои ошибки | Все упражнения, которые находятся в списке ошибок на момент запуска тренировки |

Порядок вопросов и расположение вариантов ответов перемешиваются при запуске. Вопросы внутри одной сессии не повторяются; в новой тренировке ранее встречавшиеся вопросы могут появиться снова.

**Как выглядит задание:**

> I ___ a bug yesterday.
>
> Перевод: «Вчера я нашёл баг».
>
> Возможные варианты: `find`, `found`, `have found`.

Пользователь выбирает один из трёх вариантов. После выбора сайт:

- отмечает правильный ответ;
- при ошибке выделяет выбранный неверный вариант;
- показывает объяснение и название времени;
- обновляет статистику и список ошибок;
- открывает переход к следующему вопросу.

Изменить ответ на уже отвеченный вопрос в этой сессии нельзя. Повторное нажатие не увеличивает число попыток. Кнопка перехода к следующему вопросу активируется после ответа.

После последнего вопроса отображаются число правильных ответов, размер тренировки и процент успешных ответов за эту сессию. Можно запустить новую тренировку, открыть ошибки или вернуться к маршруту.

Кнопка **«Начать заново»** создаёт новую сессию, но не сбрасывает общую статистику. Ссылка на правило открывает соответствующий урок. Возврат из урока к тренировке запускает новую сессию: позиция в незавершённой тренировке не восстанавливается.

Цифры `1`, `2`, `3` рядом с вариантами — визуальные обозначения. Отдельные горячие клавиши для ответа этими цифрами не реализованы.

### 4. Мои ошибки

Раздел помогает вернуться к заданиям, в которых возникли трудности.

В карточке ошибки отображаются:

- английское время;
- предложение с правильным ответом;
- перевод;
- объяснение;
- ссылка на правило.

По кнопке **«Повторить ошибки»** запускается отдельная тренировка. После верного ответа упражнение исчезает из списка ошибок и отмечается как закреплённое. После неверного ответа остаётся в списке. Повторные ошибки в одном задании не создают дубликатов.

Если ранее закреплённое упражнение решено неверно, оно снова попадает в ошибки и перестаёт учитываться как закреплённое до следующего правильного ответа. Поэтому количество закреплённых заданий может уменьшаться.

Когда ошибок нет, раздел показывает сообщение и предлагает перейти к обычной тренировке. Автоматического расписания повторений и уведомлений в текущей версии нет.

### 5. Английский для QA

Словарь содержит **16 карточек слов и выражений**.

| Слово или выражение | Значение |
|---|---|
| bug | Ошибка, дефект |
| test case | Тестовый сценарий |
| requirement | Требование |
| expected result | Ожидаемый результат |
| actual result | Фактический результат |
| reproduce | Воспроизвести |
| deploy | Развернуть |
| release | Релиз, выпуск |
| environment | Окружение, среда |
| database | База данных |
| request | Запрос |
| response | Ответ |
| issue | Проблема, задача |
| fix | Исправить; исправление |
| log | Журнал; запись в журнале |
| pass / fail | Пройти / не пройти проверку |

В каждой карточке есть перевод, английское предложение, его перевод и кнопка произношения словарной единицы. Например:

> **reproduce** — воспроизвести
>
> I can reproduce the bug. — Я могу воспроизвести баг.

Поиск работает без учёта регистра по английским словам, русским переводам и примерам. Отметка **«Уже знаю»** сохраняется; её можно снять. Счётчик показывает количество отмеченных карточек из 16. Отметки словаря не меняют статистику грамматических упражнений.

## Как считается прогресс

| Показатель | Правило расчёта |
|---|---|
| Закреплено упражнений | Число уникальных заданий, отмеченных как решённые правильно и не возвращённых последующим неверным ответом в ошибки |
| Прогресс темы | Закреплённые упражнения этой темы / 6 |
| Тема закреплена | Все 6 упражнений темы отмечены как закреплённые |
| Точность за всё время | Число правильных ответов / число всех ответов × 100%, с округлением до целого |
| Результат сессии | Число правильных ответов в текущей сессии / число вопросов сессии × 100%, с округлением |
| День практики | Локальная календарная дата устройства, в которую дан хотя бы один ответ |
| Дни подряд | Последовательность дней практики; если сегодня ответов ещё нет, может отображаться серия, завершившаяся вчера |

Повторные попытки входят в общую точность. Простое открытие урока или словаря не засчитывается как день практики. Учебного порога «сдал / не сдал» и отдельного экзамена нет.

## Сохранение данных

Сайт использует `localStorage` с ключом `english-step-v1` и сохраняет:

- общее число попыток и правильных ответов;
- идентификаторы закреплённых упражнений;
- идентификаторы упражнений с ошибками;
- даты практики;
- отметки знакомых слов.

Уже данные ответы сохраняются во время тренировки, без отдельной кнопки. Сама незавершённая сессия — порядок вопросов, текущая позиция и её результат — хранится только в памяти страницы.

**Особенности хранения:**

- Прогресс относится к конкретному браузеру, профилю и адресу сайта.
- Между компьютером и телефоном, разными браузерами и доменами данные не синхронизируются.
- Результаты версии на GitHub Pages и версии на другом хостинге не объединяются автоматически.
- Очистка данных сайта удаляет локальный прогресс. В приватном режиме срок хранения зависит от браузера.
- При недоступном хранилище тренировка может продолжать работать, но сохранение результатов не гарантируется; предусмотрено сообщение об ограничении.
- Кнопок экспорта, импорта и сброса всего прогресса в интерфейсе нет.

Учётной записи пользователя и серверного хранилища учебных результатов у приложения нет.

## Озвучивание

Кнопка **♪** доступна у примеров в уроках и у слов в словаре. Для произношения используются браузерные `speechSynthesis` и `SpeechSynthesisUtterance`. Приложение запрашивает английское произношение `en-US` и при наличии выбирает английский голос устройства.

Наличие и качество голоса зависят от браузера и операционной системы. Некоторые голоса могут требовать подключения к интернету. При неподдерживаемом озвучивании или ошибке воспроизведения предусмотрено текстовое сообщение. Проверки произношения пользователя и записи микрофона нет.

## Пример занятия на 10–15 минут

1. Откройте **«Мой маршрут»** и выберите предложенную тему.
2. Прочитайте правило, формулу и примеры разных типов предложений.
3. Прослушайте пример и произнесите его самостоятельно.
4. Нажмите **«Закрепить на практике»** и выполните шесть упражнений.
5. Разберите объяснения неверных ответов и повторите ошибки.
6. Откройте словарь QA и повторите несколько карточек.

При следующем посещении можно перейти к новой теме или выполнить смешанную тренировку из десяти вопросов. Это пример организации самостоятельного занятия; сайт не запускает этот план автоматически.

## Техническая реализация

Проект состоит из статических файлов. Используются HTML, CSS и обычный JavaScript без клиентского фреймворка. Сборка, установка npm-пакетов и API-ключи не требуются.

| Файл | Назначение |
|---|---|
| [index.html](index.html) | HTML-оболочка, меню и подключение ресурсов |
| [style.css](style.css) | Стили, адаптивные макеты и состояния элементов |
| [data.js](data.js) | Уроки, исходные задания и словарь |
| [app.js](app.js) | Навигация, тренировки, обработка ответов, статистика, хранилище и озвучивание |
| [.nojekyll](.nojekyll) | Файл для размещения статического содержимого на GitHub Pages без обработки Jekyll |
| [DEPLOYMENT.md](DEPLOYMENT.md) | Краткая инструкция публикации |
| README.md | Описание проекта и возможностей |

Для шрифта Manrope подключается Google Fonts; если он не загрузится, используется системный шрифт. Проверка ответов не обращается к внешней языковой модели: задания и пояснения заранее заданы в `data.js`.

CSS содержит адаптацию для узких экранов, видимую индикацию фокуса и учёт `prefers-reduced-motion`. В разметке применяются подписи кнопок, полей и индикаторов прогресса. Это описание реализованных элементов, а не заявление о полной проверке соответствия стандартам доступности.

## Локальный запуск

Нужны браузер с включённым JavaScript и любой локальный HTTP-сервер. Например, при установленном Python 3:

```bash
git clone https://github.com/anatolyhalak/english-step.git
cd english-step
python3 -m http.server 8000
```

Затем откройте [http://localhost:8000](http://localhost:8000). Для остановки сервера нажмите `Ctrl+C` в терминале.

В Windows команда запуска Python может называться `py -m http.server 8000`. Альтернативный вариант — открыть папку проекта в VS Code и запустить `index.html` через расширение Live Server.

Локальный адрес и GitHub Pages используют разные хранилища прогресса. Для предсказуемого поведения рекомендуется запуск через HTTP-сервер, а не открытие файла напрямую через `file://`.

## Обновление учебных материалов

Тексты уроков, задания и словарь находятся в `data.js`.

- `LESSONS` содержит правила, формулы, примеры и наборы упражнений.
- `WORDS` содержит словарные карточки.
- `QUESTIONS` формируется из упражнений уроков автоматически.

Задание в `rows` описывается пятью значениями:

```javascript
[
  'I ___ a bug yesterday.',
  'found',
  'find|have found',
  'Вчера я нашёл баг.',
  'Yesterday — завершённый момент прошлого. Find → found.'
]
```

Это предложение с пропуском `___`, правильный ответ, два неверных варианта через `|`, перевод и объяснение. При показе порядок трёх ответов перемешивается.

Карточка словаря задаётся четырьмя значениями:

```javascript
['bug', 'ошибка, дефект', 'I found a bug.', 'Я нашёл баг.']
```

Количество тем, упражнений в теме, общий объём и размер словаря частично прописаны в интерфейсе явно. При расширении базы нужно обновить соответствующие подписи и расчёты в `app.js`, а не только добавить записи в `data.js`.

Идентификаторы упражнений строятся из идентификатора темы и позиции задания, например `ps-0`. Перестановка или замена упражнений может изменить смысл сохранённого прогресса. При изменении структуры базы следует предусмотреть миграцию данных или отдельную версию ключа хранилища.

## Границы текущей версии

Проект охватывает шесть перечисленных времён. Другие времена, отдельные курсы артиклей, чтения и деловой переписки пока не добавлены. В базе 36 фиксированных упражнений и 16 словарных карточек.

В текущей версии также нет:

- определения уровня английского и сертификатов;
- ввода и автоматической проверки произвольного перевода;
- диалогов с AI-преподавателем;
- распознавания речи и оценки произношения;
- учётных записей, облачной синхронизации и кабинета преподавателя;
- автоматических интервальных повторений и напоминаний;
- установки как PWA и гарантированного автономного режима.

Сайт предназначен для практики выбранных тем и может дополнять занятия английским, учебник или самостоятельную работу с документацией.
